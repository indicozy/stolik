# stolik

A two-way bridge between Telegram and the Claude Code sessions on a developer's own machine.

## Language

**stolik**:
The public product name of stolik, used on the website and in packages. Russian for "little desk"; its mascot is a round blue blob carrying an amber terminal (owner, 2026-11-18; replaced the desk-on-legs idea). The name is chat-app neutral (Telegram now, Discord and others later). Tagline: "Your desk, in your pocket."
_Avoid_: tg-deck (the earlier name, dropped 2026-11-18 because it says Telegram), tg-bridge (in public copy; it stays the repo/internal name until renamed)
