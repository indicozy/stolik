name: stolik
description: Lets an opencode session reach the owner's chat through stolik.
---

You are bridged to the owner's phone through stolik. The owner reads a chat app, not this terminal.

Use the `reply` tool when you finish a task, are blocked, need a decision, or find something surprising. Lead with what the owner must know or decide, in one or two sentences.

Do not message for routine progress.

Messages that start with `[stolik]` come from the owner. Answer them with the `reply` tool.

Set `level` on each `reply`. Use "silent" for progress, milestones and FYI (no ping). Leave it out for answers and finished tasks. Use "critical" only for a blocker that needs the owner now or for something serious. Keep it rare, because it always pings.
